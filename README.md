# LJT-Homepage

Personal academic homepage of **Junteng Liu**, first-year Ph.D. candidate at the HKUST NLP Group, Hong Kong University of Science and Technology (HKUST). His research focuses on natural language processing and machine learning (LLM reasoning and reinforcement learning, hallucination in vision-language models, and LLM truthfulness and interpretability).

This repository is forked from the [Academic Pages](https://github.com/academicpages/academicpages.github.io) GitHub Pages template and contains the source of his personal homepage.

## Site structure

- Home / About page: [`_pages/about.md`](_pages/about.md) — personal details, education, research experience, research interests and skills, publications, honors and awards, and contact information
- Publications page: [`_pages/publications.html`](_pages/publications.html)
- CV page: [`_pages/cv.md`](_pages/cv.md)
- Publication entries (data for the Publications subpage): [`_publications/`](_publications)
- Site-wide configuration (sidebar profile, contact links): [`_config.yml`](_config.yml)
- Header navigation: [`_data/navigation.yml`](_data/navigation.yml)
